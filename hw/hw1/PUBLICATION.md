## Публичные артефакты

- В трейсе оставлены имена операций, связи parent/child и точные длительности. Trace/span ID синтетические, время относительно начала трейса. Resource metadata, SQL, attributes, events и links удалены.
- В pg_stat_statements сохранены имена запросов, calls, rows и времена; SQL ищется по имени в публичном исходном коде. Статистика времени не изменена.
- Служебные UUID и адреса в журналах заменены заглушками, локальные пути пользователя заменены на `/home/student`. Из снимков Prometheus оставлены агрегаты HTTP/eventbus/database.
- Для каждого k6 summary проверено полное равенство раздела metrics. Для каждого трассировочного JSON проверено равенство имён, количества и суммарных длительностей span. Код реализации и тестов не менялся.
- Оригинальные измеренные коммиты и сырые артефакты сохранены локально в ветке `hw1-measured`. Например: `git show hw1-measured:hw/hw1/artifacts/baseline/slow-trace.json`.

Публичные trace ID не предназначены для поиска в локальном Tempo. Для диагностики живого стенда используйте исходные локальные артефакты или новый запуск сценария.
